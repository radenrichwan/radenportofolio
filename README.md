## ✨ Fitur Utama Website

### 🌓 1. Dual Theme System (Dark Mode & Light Mode)
- **Obsidian / Slate Palette**: Tema gelap dirancang dengan palet *deep slate* (`#0c0e14`, `#141822`, `#1c2230`) yang nyaman di mata tanpa silau (*low-strain editorial aesthetic*), dipadukan dengan aksen ungu pastel (`#a78bfa`).
- **Anti-Flicker Pre-Render**: Menggunakan *inline head script* untuk mendeteksi preferensi tema dari `localStorage` atau OS (*prefers-color-scheme*) sebelum render halaman, mencegah kedipan putih (*zero-FOUC*).
- **Smooth Transition**: Perubahan warna latar belakang, kartu, border, dan teks berlangsung halus dan konsisten.

### 🌐 2. Bilingual Support (ID / EN)
- **Saklar Bahasa Instan**: Tombol toggle `[ ID | EN ]` pada bilah navigasi atas.
- **Kamus Terjemahan Menyeluruh**: Menerjemahkan seluruh bagian portofolio (Navigasi, Hero, Tentang, Keahlian, Pengalaman, Proyek, Pendidikan, hingga Kontak) secara *real-time* tanpa perlu memuat ulang halaman (*zero-reload*).
- **Penyimpanan Lokal**: Pilihan bahasa tersimpan otomatis di `localStorage`.

### 🎓 3. Education 3-Columns Grid & Google Search Link
- **Tata Letak Horizontal Sejajar**: Bagian riwayat pendidikan disusun dalam format *3-columns grid* di desktop, lengkap dengan logo sekolah resmi, badge tahun periode, dan status kejuruan.
- **Pencarian Google Otomatis**: Menekan nama sekolah langsung membuka hasil pencarian Google terkait profil sekolah tersebut di tab baru:
  - **SMK Negeri 20 Jakarta** (2024 – 2027)
  - **SMP Negeri 166 Jakarta** (2021 – 2024)
  - **SD Negeri 14 Ragunan** (2015 – 2021)

### 🧭 4. Dynamic Scroll-Spy & Section Indicators
- **Floating Page Navigation Capsule**: Kapsul melayang di pojok kanan bawah (`01 / 07` s.d. `07 / 07`) yang dinamis mendeteksi posisi *scroll* layar, dilengkapi tombol panah navigasi *smooth-scroll*.
- **Static Section Indicators**: Penanda nomor urut statis bernuansa *monospaced muted* di pojok kanan atas setiap section container.
- **Scroll Progress Bar**: Garis progres baca tipis di bagian paling atas layar.

## 🚀 Cara Menjalankan Secara Lokal

1. **Clone repositori**:
   ```bash
   git clone https://github.com/radenrichwan/raden-portfolio.git
   cd raden-portfolio
   ```

2. **Jalankan web server lokal**:
   - **Opsi 1**: Menggunakan ekstensi **Live Server** di Visual Studio Code (klik kanan pada `index.html` → *Open with Live Server*).
   - **Opsi 2**: Menggunakan PHP built-in server:
     ```bash
     php -S localhost:8000
     ```
   - **Opsi 3**: Menggunakan Node.js `npx serve`:
     ```bash
     npx serve .
     ```

3. Buka peramban di URL `http://localhost:8000` (atau port yang ditentukan).
